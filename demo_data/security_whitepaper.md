## 1. Overview
ThinkShield is the end-to-end security portfolio covering the device lifecycle:
supply chain, hardware, firmware, operating system, and decommissioning.

## 2. Supply Chain Assurance
ThinkShield provides supply-chain transparency through a verifiable bill of
materials and tamper-evident packaging. Select configurations support a factory
attestation certificate that lets IT verify a device has not been altered in transit.

## 3. Firmware Protection
- Self-healing BIOS automatically restores firmware to a known-good state if
  corruption or tampering is detected.
- Secured-core support enforces firmware measurement and verified boot.

## 4. Authentication and Identity
- FIDO2 passwordless authentication is supported via the platform authenticator.
- A discrete Trusted Platform Module (dTPM 2.0) anchors keys in hardware.

## 5. Data Protection and Decommissioning
- Full-disk self-encrypting drive (SED) options with hardware-based encryption.
- A secure-wipe utility performs a verifiable cryptographic erase before resale or disposal.

## 6. Certifications and Compliance
- The information security management program is certified to ISO 27001.
- Select firmware components are evaluated under Common Criteria EAL4+.
- Designed to support NIST SP 800-193 firmware resilience guidelines.
